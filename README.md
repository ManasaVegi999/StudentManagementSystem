# Student Management System

A simple Student Management System developed using Python and Object-Oriented Programming (OOP) concepts. This project allows users to add student records, display student details, calculate total and average marks, and search for students using their roll numbers.

## Project Overview

The Student Management System is a beginner-friendly Python project created to practise OOP concepts and basic programming logic.

## Features

- Add new student records
- Display all student details
- Calculate total marks
- Calculate average marks
- Search students using roll number
- Interactive menu-driven interface
- Encapsulation using private attributes
